            发布信息#

            FlagOS 容器镜像构建基础设施。FlagOS 的镜像是分层发布的——厂商 base 镜像、 其上的 FlagGems runtime 镜像，以及（即将推出的）application 镜像。

            • 概览 —— 各镜像层如何关联与命名。
            • 基础镜像 —— 操作系统 + 厂商 SDK。每个后端的内容与运行命令。
            • 运行时镜像 —— Python + 软件栈（Torch、Triton、FlagTree、FlagGems）。
            • 应用镜像 —— vLLM、Megatron-LM、SGLang（规划中）。
            • 使用 · 贡献

            本文档中的所有事实信息都由 configs.yaml + base/ 自动生成，因此不会与源头脱节。
