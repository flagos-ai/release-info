            mthreads-musa4.3.6

            内容

            • 镜像: flagos-runtime-mthreads-musa4.3.6:latest (tag 方案待定)
            • Python: 3.10
            • 宿主机驱动: 5.2.0-server

            主要 Python 软件包

            • flag_gems
            • flagtree==0.6.0+mthreads3.6
            • mkl==2024.0.0
            • torch==2.9.0+musa.4.3.6
            • torch_musa==2.9.0
            • triton==3.6.0+git89458660

            灰色 = 备用编译器（默认使用 flagtree；仅当 flagtree 不可用时才回退到 triton）。

            环境变量

            • LD_LIBRARY_PATH=${VIRTUAL_ENV}/lib:${LD_LIBRARY_PATH}
            • MTHREADS_VISIBLE_DEVICES=all

            运行

            使用容器工具包（可选） (KUAE Cloud Native Toolkits (MT Container Toolkit) >= 2.1.0):

            docker run --rm -it --runtime mthreads --env MTHREADS_VISIBLE_DEVICES=all flagos-runtime-mthreads-musa4.3.6:latest bash

            无需工具包 —— 直接使用 docker / podman:

            docker run --rm -it --device /dev/mtgpu.0 --device /dev/dri -v /usr/bin/mthreads-gmi:/usr/bin/mthreads-gmi:ro flagos-runtime-mthreads-musa4.3.6:latest bash
