      ascend-cann8.5.0

      前置条件 link

      • 架构: aarch64
      • 芯片型号: Ascend 910B
      • 宿主机驱动: 25.5.0
      • 容器工具包 (可选) : Ascend-docker-runtime >= 6.0.RC3

      镜像内容 link

      基于 link

      harbor.baai.ac.cn/flagos-base/flagos-base-ascend-cann8.5.0:2.1.1 open_in_new

      Python link

      3.11

      主要 Python 软件包 link

      • flag_gems
      • flagtree==0.6.0+ascend3.2
      • torch-npu==2.9.0
      • torch==2.9.0+cpu
      • triton-ascend==3.2.0

      切换编译器 link

      本镜像同时包含 FlagTree（默认）和 Triton。在容器内执行 compiler triton 可切换到 Triton，执行 compiler flagtree 切回，执行 compiler 查看当前编译器。

      启动 link

      使用容器工具包 (可选)：

        docker run --rm -it \
  -e ASCEND_VISIBLE_DEVICES=0 \
  harbor.baai.ac.cn/flagos-runtime/flagos-runtime-ascend-cann8.5.0:latest bash

      无需工具包 —— 直接使用 docker / podman：

        docker run --rm -it \
  --device /dev/davinci0 \
  --device /dev/davinci_manager \
  --device /dev/devmm_svm \
  --device /dev/hisi_hdc \
  -v /usr/local/Ascend/driver:/usr/local/Ascend/driver \
  -v /usr/local/dcmi:/usr/local/dcmi \
  -v /usr/local/sbin/npu-smi:/usr/local/sbin/npu-smi \
  harbor.baai.ac.cn/flagos-runtime/flagos-runtime-ascend-cann8.5.0:latest bash

      验证 link

      在容器内，确认加速器可见：

        source /usr/local/Ascend/ascend-toolkit/set_env.sh && npu-smi info
