            mthreads-musa5.2.0

            内容

            • 镜像: harbor.baai.ac.cn/flagos-base/flagos-base-mthreads-musa5.2.0:2.1.1-18-ga423af1
            • 基础系统: ubuntu:24.04
            • 宿主机驱动: 5.2.0-server

            系统软件包

            • build-essential
            • ca-certificates
            • cmake
            • curl
            • g++
            • gcc
            • libelf1
            • libgfortran5
            • libnuma-dev
            • libopenmpi-dev
            • libpython3-dev
            • openmpi-bin

            SDK 软件包

            • MUSA Toolkits 5.2.0
            • MCCL 2.4.0
            • muDNN 3.4.0

            环境变量

            • LD_LIBRARY_PATH=/usr/local/musa/lib
            • MUSA_HOME=/usr/local/musa
            • PATH=/usr/local/musa/bin:${PATH}

            运行

            使用容器工具包（可选） (KUAE Cloud Native Toolkits (MT Container Toolkit) >= 2.1.0):

            docker run --rm -it --runtime mthreads --env MTHREADS_VISIBLE_DEVICES=all harbor.baai.ac.cn/flagos-base/flagos-base-mthreads-musa5.2.0:2.1.1-18-ga423af1 bash

            无需工具包 —— 直接使用 docker / podman:

            docker run --rm -it --device /dev/mtgpu.0 --device /dev/dri -v /usr/bin/mthreads-gmi:/usr/bin/mthreads-gmi:ro harbor.baai.ac.cn/flagos-base/flagos-base-mthreads-musa5.2.0:2.1.1-18-ga423af1 bash
