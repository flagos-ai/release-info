        build-infra#

        FlagOS container image build infrastructure. This repo defines and builds the base images — a vendor’s SDK and toolchain on an OS base — that FlagOS runtime images are built on.

        • Overview — how images are layered and named.
        • Images — the supported vendor/backend catalog and a per-image reference (what’s installed, the environment, dependencies).
        • Usage — pulling and running the images.
        • Contribution — adding a new vendor/backend.

        Every fact on these pages is generated from configs.yaml + base/, so the docs cannot drift from the source.
