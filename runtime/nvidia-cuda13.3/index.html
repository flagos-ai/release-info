            nvidia-cuda13.3

            Contents

            • Image: flagos-runtime-nvidia-cuda13.3:latest (tag scheme being finalized)
            • Python: 3.12
            • Host driver: 610.43.02

            Major Python packages

            • flag_gems
            • flagtree==0.6.0
            • torch==2.11.0+cu130
            • torchaudio==2.11.0+cu130
            • torchvision==0.26.0+cu130
            • triton==3.6.0

            Greyed = fallback compiler (flagtree is the default; triton is used only if flagtree is unavailable).

            Environment

            • NVIDIA_DRIVER_CAPABILITIES=compute,utility
            • NVIDIA_VISIBLE_DEVICES=all

            Run

            With the container toolkit (optional) (nvidia-container-toolkit):

            docker run --rm -it --gpus all flagos-runtime-nvidia-cuda13.3:latest bash

            Without a toolkit — plain docker / podman:

            docker run --rm -it --device /dev/nvidia0 --device /dev/nvidiactl --device /dev/nvidia-uvm -v /usr/bin/nvidia-smi:/usr/bin/nvidia-smi:ro -v /usr/lib/x86_64-linux-gnu/libnvidia-ml.so.1:/usr/lib/x86_64-linux-gnu/libnvidia-ml.so.1:ro -v /usr/lib/x86_64-linux-gnu/libcuda.so.1:/usr/lib/x86_64-linux-gnu/libcuda.so.1:ro flagos-runtime-nvidia-cuda13.3:latest bash
